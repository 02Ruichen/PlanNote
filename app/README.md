# PlanNote · Web 版（v2）

把原来那个 tkinter 桌面版 PlanNote，重做成一个**纯前端网页应用**：
点开链接就能用，可以「安装到桌面」当 App，数据留在自己的设备上。

---

## 怎么打开

**方式一：直接双击 `index.html`**
最简单的本地体验。数据存在浏览器 localStorage 里，关掉再开还在。

**方式二：起一个本地服务（推荐，能体验 PWA 安装）**

```bash
cd app
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

Chrome 地址栏右侧会出现「安装」按钮，装完就是一个独立窗口的桌面应用。

**方式三：部署到任意静态托管**
整个 `app/` 目录都是静态文件，传到任何静态托管（Vercel / Netlify / GitHub Pages / 对象存储）就能得到一个可分享的链接。

---

## 它现在有什么

| 功能 | 说明 |
|---|---|
| 日计划 | 一句话回车就能加；可设分类、难度（1–5）、时间段、备注 |
| 周视图 | 七天一屏，看这周的分布和完成率 |
| 月视图 | 日历网格，有内容的日子会亮起来 |
| 统计 | 本周完成率、连续打卡天数、最近 7 天柱状图、近 30 天精力分配 |
| AI 周报 | 一键把本周记录整理成周报，可复制、可下载 `.md` |
| 备份 | 一键导出 / 导入 JSON，换设备不丢数据 |
| 深色模式 | 跟着作息换一身衣服 |

快捷键：`N` 新建、`Esc` 关闭弹窗、输入框里回车即添加。

---

## 数据存在哪

- 通过网址访问 → 存在浏览器 **IndexedDB**
- 直接双击本地文件 → 自动降级到 **localStorage**
- 两种情况都可以在「设置 → 数据」里导出 JSON 备份

没有任何服务器接收你的记录。AI 周报默认走**本地规则生成**，不联网也能出稿；
需要真 AI 时，在设置里三选一：走自己的代理后端 / 填自己的 API Key。

---

## 技术

- 原生 JS + CSS，零构建、零依赖
- IndexedDB（含 localStorage 降级）
- PWA：`manifest.webmanifest` + Service Worker，可离线打开
- 莫兰迪色系设计变量（`assets/theme.css` 顶部一处定义，全站取用）

## 目录

```
app/
├── index.html              入口
├── manifest.webmanifest    PWA 配置
├── sw.js                   离线缓存
├── icons/                  图标
└── assets/
    ├── theme.css           设计系统（颜色/圆角/阴影/字号）
    ├── db.js               数据层（存储 + 日期工具）
    ├── report.js           周报引擎（本地生成 / 代理 / 自带 Key）
    └── app.js              界面与交互
```
