# PlanNote · Web 版（v2）

把原来那个 tkinter 桌面版 PlanNote，重做成一个**纯前端网页应用**：
点开链接就能用，可以「安装到桌面」当 App，数据留在自己的设备上。

---

## 怎么打开

**方式一：直接双击 `app.html`**
最简单的本地体验。数据存在浏览器 localStorage 里，关掉再开还在。
（`index.html` 是作品介绍页，`app.html` 才是应用本体。）

**方式二：起一个本地服务（推荐，能体验 PWA 安装）**

```bash
cd app
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

Chrome 地址栏右侧会出现「安装」按钮，装完就是一个独立窗口的桌面应用。

**方式三：部署到任意静态托管**
整个 `app/` 目录都是静态文件，传到任何静态托管（Vercel / Netlify / GitHub Pages / 对象存储）就能得到一个可分享的链接。

## 它现在有什么

| 功能 | 说明 |
|---|---|
| 日计划 | 两个写清用途的按钮：「添加任务」直接记下，「详细填写」展开完整表单（会自动带上你已打的字） |
| 模块 | 工作 / 学习 / 生活 / 健康 之外可以自己新建（如「长期开发」）；日视图顶部按模块筛选，新建任务自动归入当前模块 |
| 周视图 | 七天一屏，看这周的分布和完成率 |
| 月视图 | 日历网格，有内容的日子会亮起来 |
| 统计 | 本周完成率、连续打卡天数、最近 7 天柱状图、近 30 天精力分配 |
| AI 周报 | 接入 API Key 后，一键让大模型把本周记录写成周报，可复制、可下载 `.md` |
| 周报范围 | 「全部模块」或指定某一个项目单独出周报；每份按「周 + 范围」分别留存，切来切去看不丢 |
| 周报规则 / 模板 | 粘贴公司模板、格式要求、历史样例或提示词；生成时作为硬性格式要求，优先于默认四段结构 |
| 备份 | 一键导出 / 导入 JSON，换设备不丢数据 |
| 深色模式 | 跟着作息换一身衣服 |

快捷键：`N` 新建、`Esc` 关闭弹窗、输入框里回车即添加。

按钮的分工只有一句话：**「添加任务」负责快，「详细填写」负责全**。两者都在同一个输入栏里，不会有两个入口打架。

## 数据存在哪

- 通过网址访问 → 存在浏览器 **IndexedDB**
- 直接双击本地文件 → 自动降级到 **localStorage**
- 两种情况都可以在「设置 → 数据」里导出 JSON 备份

没有任何服务器接收你的记录，也不需要账号。

## 周报规则 / 模板

在「AI 周报」页顶端有一张可展开的「周报规则 / 模板」卡片：

- 把**公司周报模板**、格式要求、字段顺序、篇幅限制、历史样例，或一句提示词，原样贴进文本框
- 点「保存规则」（或直接失焦）即生效，卡片上会显示「已设置 · 生成时严格遵循」
- 生成时这段内容会被放进提示词最前面，并声明为**硬性要求**；与默认的「四段结构」冲突时，以你的规则为准
- 想回到默认结构，点「清空」即可

> 规则里可以写：标题格式、小节划分、每节条数、是否用表格、语气、禁止出现的说法……写得越具体，出来的越接近你们公司的样子。

## 按项目出周报

周报页顶部有一排「周报范围」：默认是**全部模块**，点某个项目就只统计这个项目的记录。

- 发出去的提示词里会明确写「只统计「××」这一个模块，其它模块不要提及」，避免模型把别的事也写进来
- 每份周报按「周 + 范围」分开存，切到别的项目再切回来，原来那份还在
- 想合起来写，点回「全部模块」重新生成即可

> 这里的「项目」就是模块：设置里可以自己新建、改名、换颜色，任务按模块归类。

## 测试

`test/` 下有一套端到端测试，用无头 Chrome 真点真跑，覆盖三件事：

1. 自定义创建项目，并在项目里建任务、刷新后仍在
2. 按指定项目生成周报（断言发给模型的提示词里只有该项目记录）
3. 周报规则真实生效（断言规则原文进入提示词、优先级声明、渲染结果）

```bash
cd test
node run-tests.mjs          # 用本地模拟接口跑，不花钱、不联网
node run-tests.mjs --live   # 加真实调用（把 Key 写进 test/.key，或用 PN_API_KEY 传入）
```

测试全程在**一次性的临时浏览器目录**里进行，跑完整个目录删掉，
不会碰你浏览器里已有的任务、模块和 Key。

## 接入 AI 周报（三步）

1. 去 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请一个 API Key（有免费额度）
2. 打开应用 → 左下角「设置」→ 粘进 **API Key** 那一栏
3. 点「测试连接」，看到「连接正常」就好了

之后回到「AI 周报」页点生成，就是真的由大模型写的周报。

- **Key 存在哪**：只写在你这台设备的浏览器里，不上传任何地方。导出备份时也**不会**带上 Key。
- **什么操作都不会弄丢它**：保存周报规则、切模块、导入备份、甚至「清空全部数据」都只改对应字段，Key 与地址、模型一并保留（清空时会明确告诉你「AI 配置已保留」）。
- **能不能换别家**：可以。服务地址填任何**兼容 OpenAI 格式**的接口都行（OpenAI、Kimi、通义、自建代理…），换一下地址和模型名即可。
- **为什么不用后端**：这些 API 支持浏览器直接调用（已实测），少一个服务器就少一份维护和费用，Key 也不用交给别人。

## 技术

- 原生 JS + CSS，零构建、零依赖
- IndexedDB（含 localStorage 降级）
- PWA：`manifest.webmanifest` + Service Worker，可离线打开
- AI：`fetch` 直连 OpenAI 兼容接口，无后端

## 部署

站点通过 GitHub Actions 发布到 GitHub Pages，只上传 `app/` 目录：

- 工作流：`.github/workflows/pages.yml`
- 触发：推到 `main` 且 `app/**` 有改动，或手动触发
- 地址：https://02ruichen.github.io/PlanNote/

**发版注意**：改动前端资源后，记得把 `sw.js` 里的 `CACHE` 版本号加一，
否则老访客会一直拿到缓存里的旧版本。
